# Noctalia plugins

Plugins written for this setup live in their own public repositories, so other people can find, install and report issues on them:

| Plugin | Repository | Store |
| --- | --- | --- |
| ROG Control (`genuinemoron/rog-control`): performance modes, charge limit, graphics mode, overdrive, keyboard lighting, fans and temperatures through asusd | [GenuineMoron/noctalia-rog-control](https://github.com/GenuineMoron/noctalia-rog-control) | In the Noctalia plugin store (merged in [community-plugins #1453](https://github.com/noctalia-dev/community-plugins/pull/1453)) |

On this laptop the plugin runs from a local clone: `~/.local/share/noctalia/plugins/rog-control` is a symlink to `~/Projects/noctalia-rog-control`, so edits there hot-reload in the shell.
